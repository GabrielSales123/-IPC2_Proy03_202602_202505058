# AutorizadorDTE

## Descripción

AutorizadorDTE es una aplicación desarrollada con ASP.NET Core que permite procesar y autorizar facturas electrónicas DTE, validar contribuyentes mediante el RTU y consultar información relacionada con las facturas.

## Funcionalidades

- Procesamiento y autorización de facturas.
- Validación de NIT y consulta de contribuyentes.
- Actualización de información del RTU.
- Consulta de resúmenes de IVA y facturación por rango de fechas.
- Generación de reportes de errores.
- Almacenamiento de información en archivos JSON.

## Tecnologías

- C# y ASP.NET Core Web API.
- Razor Pages para la interfaz web.
- Archivos JSON para el almacenamiento de datos.

## Estructura del proyecto

- `BackendAPI`: lógica de negocio, controladores y servicios.
- `FrontendWeb`: interfaz web y comunicación con la API.

## Ejecución

Abre la solución en Visual Studio, configura los proyectos de inicio y ejecuta la aplicación para acceder a la interfaz web y sus funcionalidades.
